# 직원 이탈 분석 결과

전체 1,470명 중 퇴사 표시 인원은 **237명(16.12%)**입니다.

| 집단 | 퇴사 비율 | 나머지 직원 | 차이 |
|---|---:|---:|---:|
| 초과근무 | 30.53% | 10.44% | +20.09%p |
| 근속 2년 이하 | 29.82% | 11.97% | +17.86%p |
| 직무만족도 2점 이하 | 19.68% | 13.87% | +5.81%p |
| 동일 직급 급여 하위 25% | 17.57% | 15.64% | +1.93%p |
| 승진대기 5년 이상 | 14.23% | 16.53% | −2.30%p |

초과근무·근속 2년 이하·낮은 직무만족도 집단은 Holm 보정 후에도 유의한 차이를 보였습니다. 동일 직급 급여 하위 25%와 승진대기 5년 이상 집단의 차이는 유의하지 않았습니다.

여러 변수를 함께 고려한 회귀 결과는 다음과 같습니다.

| 변수 | 조정 오즈비(OR) | 95% 신뢰구간 |
|---|---:|---:|
| 초과근무 있음 vs 없음 | 4.724 | 3.448–6.473 |
| 직무만족도 1점 증가 | 0.729 | 0.636–0.836 |
| 근무환경 만족도 1점 증가 | 0.707 | 0.614–0.814 |
| 근속 1년 증가 | 0.917 | 0.874–0.961 |
| 월급 1,000단위 증가 | 0.867 | 0.822–0.915 |
| 승진대기 1년 증가 | 1.132 | 1.054–1.215 |

**우선 점검 과제:** 초과근무 집단의 업무량·인력배치, 저연차 직원의 온보딩·멘토링, 낮은 만족도 집단의 직무 경험 개선.

가상·교육용 데이터의 표본 내 결과입니다. OR은 확률 배수가 아니며, 관찰된 관련성이 인과관계나 정책 효과를 의미하지 않습니다.
