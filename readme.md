# 그리핀도르 모자(Sorting Hat)

## 웹 화면으로 실행하기 (Streamlit)

프로젝트 폴더의 PowerShell에서 최초 한 번 실행합니다.

```powershell
python -m venv .venv
.\.venv\Scripts\python -m pip install -r requirements.txt
```

이후 아래 명령으로 웹 화면을 실행합니다. 브라우저에서 `http://localhost:8501`에 접속하세요. 종료는 터미널에서 `Ctrl+C`입니다.

```powershell
.\.venv\Scripts\python -m streamlit run app.py
```

- 샘플 직원 20명으로 바로 시작하며, 같은 형식의 UTF-8 CSV를 업로드할 수 있습니다.
- 직원 역량·성향 탭에서 직원을 선택하고, 숫자가 표시된 가로 막대로 개인 점수와 대상 직원 평균을 비교합니다.
- 왼쪽에서 부서, 팀 인원 또는 직급별 인원을 정하고 **팀 조합 분석하기**를 누릅니다.
- 팀 조합 비교 탭에서 역량·역할 충족도와 성향 유사성/다양성 순위, 팀 평균 레이더 차트, 팀원별 점수를 확인하고 전체 결과를 CSV로 내려받습니다.
- 조건을 변경하면 다시 분석해야 합니다. 화면 멈춤을 줄이기 위해 1회 분석은 최대 20,000개 조합으로 제한합니다.

후보 팀은 서로 직원을 공유할 수 있으며, 전체 직원을 겹치지 않게 배치한 결과는 아닙니다. 현재 유사성/다양성 점수는 성향의 거리 기반 지표이며 업무성과 예측이나 검증된 인사 추천 점수가 아닙니다.

### 이 프로젝트에 Streamlit을 쓰는 이유

현재 분석은 Python/pandas와 `src/` 함수로 구현되어 있습니다. Streamlit은 이 함수를 직접 호출하면서 입력 위젯과 차트를 웹에 표시하므로 노트북 셀 실행 없이 탐색하기에 적합합니다. Vue 3로도 구현할 수 있지만 기존 Python 분석을 연결할 API 서버와 프런트엔드 상태/차트 코드를 별도로 관리하는 구성이 보통 필요합니다. 세밀한 UI, 복잡한 화면 전환과 서비스 확장이 중심이 되면 Vue 3를 검토할 수 있습니다.

참고: [Streamlit 앱 만들기](https://docs.streamlit.io/get-started/tutorials/create-an-app), [Vue 소개](https://vuejs.org/guide/introduction).

기존 노트북과 `python main.py` 실행 방식도 사용할 수 있습니다.

> **Sorting Hat, 통칭 그리핀도르 모자는 개인-환경 적합성(Person-Environment Fit) 이론을 기반으로 개인과 조직·직무 간의 적합성을 분석하여 알맞은 팀 조합을 추천해주는 HR Analytics 프로젝트입니다**


기업의 채용과 인력배치에서는 지원자의 역량뿐만 아니라 조직문화, 직무 특성, 개인의 가치관과 성향 등 다양한 요소가 함께 고려됩니다.
조직행동론에서는 이러한 관계를 **개인-환경 적합성(Person-Environment Fit, P-E Fit)**이라는 개념으로 설명합니다.

해당 프로젝트는 P-E Fit 이론을 기반으로,
Big 5 이론을 활용하여 사원의 직위, 성향, 가치관, 업무태도에 관한 더미데이터를 생성한 뒤, 
어떤 조직원과 한 팀이 되었을 때 최대 업무효율 발휘 및 직무 만족도가 최상이 되는지를 분석하는 모델입니다.

### 역량과 성향 함께 참고하기

프로젝트 유형을 선택하고 필요 역량·역할 및 목표 수준을 조정하면, 동일한 팀 후보에서 업무 역량 충족도와 Big Five 성향을 함께 비교할 수 있습니다. 기본 정렬은 업무역량 상호 보완 우선이며 성향 유사성 또는 다양성으로도 정렬할 수 있습니다. 성향을 역량 점수에 합산하지 않으며, 두 자료를 함께 검토하는 방식입니다.

역량 충족도는 필요 역량별 팀 내 최고 점수 / 목표 수준(최대 100%)의 평균입니다. 역할 충족도는 필요한 역할 중 담당자가 있는 비율입니다. 수준·공유 점수는 역량 70% + 역할 30% + 공유 보너스(최대 10점)이며 검증된 성과 예측값이 아닙니다. 투입 가능률은 참고값으로 표시됩니다.

샘플 20명은 가상 데이터입니다. 기존 Big Five 점수에 별도로 만든 기획·디자인·개발·데이터 분석·운영 역량과 담당 역할, 투입 가능률을 추가했습니다. 역량은 성향에서 추정하지 않습니다. CSV 업로드에는 기존 열 외에 `role`, `planning`, `design`, `engineering`, `analytics`, `operations`, `availability`가 필요합니다. 역할은 기획/디자인/개발/데이터 분석/운영 중 하나이며 모든 역량 및 투입 가능률은 0~100입니다. 기존 성향 전용 CSV에는 이 열을 추가해야 합니다.

### 상호 보완 우선 매칭

1. 필요 역량을 서로 다른 팀원이 하나씩 맡도록 최적으로 배치하고, 목표 충족률(역량별 최대 100%)의 평균을 상호 보완성으로 계산합니다. 담당자가 없는 역량은 0점입니다. 한 명에게 강점이 몰린 팀보다 여러 팀원이 나누어 맡는 팀이 우선됩니다. 이 배치는 점수 계산용이며 실제 업무 배정은 아닙니다.
2. 보완성이 같은 후보는 수준·공유 점수로 비교합니다. 공유 보너스가 높은 팀도 보완성이 낮으면 앞설 수 없습니다.
3. 전체 5개 역량 중 2순위(공동 순위는 경쟁 순위)이면서 목표의 50% 이상이거나, 목표의 80% 이상인 역량에 대해 자신보다 점수가 높고 목표를 충족하는 동료가 있으면 공유 연결을 인정합니다. 필요 역량만 대상으로 하며 같은 역량의 동료를 중복 가산하지 않습니다.
4. 각 연결의 min(학습자 역량/목표, 1)을 합산한 뒤 (팀원 수−1) × 필요 역량 수로 나누고 10을 곱합니다. 팀 규모에 따라 연결 개수만으로 유리해지지 않도록 정규화합니다. 단독 팀은 보너스가 0입니다.

팀 상세의 ‘지식 공유 보너스 근거’에서 역량별 동료와 점수를 확인할 수 있습니다. 이는 공유 가능성을 나타내는 가정이며 실제 설명 능력이나 학습 성과를 측정한 결과는 아닙니다. 성향 기준 정렬은 별도의 탐색 옵션으로 유지합니다.
