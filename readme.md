# 직원 이탈 영향요인 분석 및 Retention 전략 도출

HR 문제를 데이터로 정의하고, 통계적으로 검토한 뒤 조직 차원의 인사 의사결정으로 연결하는 ADsP 포트폴리오입니다. 개인별 퇴사 예측·평가 대신 집단별 이탈 특성, 통계적 관련성, 정책 점검안을 제공합니다.

## 실행

프로젝트 루트에서 실행합니다. 검증 환경: Windows, Python 3.14.7.

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe main.py
.\.venv\Scripts\python.exe -m streamlit run app.py
.\.venv\Scripts\python.exe -m pytest -q
```

`main.py`는 집계 결과를 `reports/`에 재생성합니다. Streamlit은 같은 분석 모듈을 사용하고 CSV 내용이 바뀌면 캐시가 갱신됩니다. 임의 CSV 업로드와 개인 검색은 제공하지 않습니다.

## 데이터와 한계

- 입력: `data/raw/WA_Fn-UseC_-HR-Employee-Attrition.csv`. 사용자가 제공한 루트 CSV를 그대로 복사했습니다.
- 1,470행, 35개 원본 컬럼, 퇴사 표시 237명(16.12%). 요구한 변수는 모두 존재합니다.
- IBM HR Analytics Employee Attrition & Performance 계열의 **가상·교육용 공개 데이터**입니다. 실제 IBM 직원 자료로 해석하지 않습니다.
- [공개 데이터 설명](https://www.kaggle.com/datasets/pavansubhasht/ibm-hr-analytics-attrition-dataset), [가상 자료임을 명시한 데이터 요약](https://zenodo.org/records/4088439). 로컬 파일의 최초 다운로드 경로와 원배포 파일과의 동일성은 확인되지 않았습니다. 재배포 전 해당 배포처의 이용조건을 확인해야 합니다.
- 관찰기간·퇴사시점·정책 시행·추적 자료가 없습니다. 퇴사율은 표본 내 비율이며 연간 이직률이나 미래 이탈 확률이 아닙니다.
- 급여·통근거리 단위는 로컬 메타데이터가 없어 원자료 단위로 표시합니다.
- 가상 자료에 대한 p-value·신뢰구간은 분석 절차 시연입니다. 실제 조직 모집단에 일반화할 수 없습니다. 관련성은 인과효과가 아닙니다.

```text

  logistic_regression.py # 4. 조정 OR·95% CI·VIF
```

## 분석 설계와 판단 근거

1. **전처리**: Attrition Yes/No를 1/0으로 변환합니다. 잘못된 타깃·음수·무한대·만족도 범위를 검증합니다. EmployeeNumber는 식별자라 제외하고 EmployeeCount, Over18, StandardHours는 상수라 제외합니다. 결측·중복은 보고하며 IQR 이상치는 제거하지 않습니다. 고연차·고보상을 오류로 간주할 근거가 없기 때문입니다. 타깃 결측은 제외하고 나머지는 분석별 완전사례를 사용합니다. 변수는 임의 생성하지 않으며 원자료에서 명시적으로 파생한 구간만 추가합니다.
2. **EDA**: 부서·직무·직급·근속·초과근무·직무만족·급여 사분위·승진대기별 비율을 분모와 Wilson 95% CI로 제시합니다. 30명 미만 집단은 최고 비율 설명에서 제외합니다. EDA의 결측 범주는 별도 집단으로 표시합니다.
3. **가설검정**: 초과근무/부서×퇴사는 Pearson 카이제곱, 기대빈도가 작은 2×2는 Fisher 검정입니다. 희소 다범주 표는 검정을 생략합니다. 급여·근속·만족도는 Welch t-test, 직무별 만족도는 Welch ANOVA로 등분산을 강제하지 않습니다. 만족도는 순서형이므로 Mann–Whitney 및 Kruskal–Wallis를 보완합니다. H0/H1, 통계량, p, Holm 보정 p, α=.05, 판단, 평균 차이/효과크기, 가정을 제공합니다. ANOVA 유의성은 특정 직무 쌍의 차이를 뜻하지 않습니다.
4. **로지스틱 회귀**: 초과근무, 직무·환경 만족도, 워라밸, 근속, 급여, 통근, 승진대기, 부서를 사전 선택했습니다. 급여는 1,000단위로 환산합니다. 범주형 기준은 정렬상 첫 범주(No, Human Resources)입니다. 직급·총경력·직무기간은 급여/근속과의 중복과 간결성을 고려해 기본 모델에서 제외했습니다. 이는 잔여 교란을 제거한 모형이 아닙니다. 만족도·연속변수는 로그오즈에 선형인 추세를 가정합니다. 계수, OR, 개별 95% CI, 미보정 p, 더미별 VIF를 제공합니다. 단위가 다른 OR로 중요도 순위를 매기지 않습니다. 변수선택에 p-value를 쓰지 않으며 전체 자료로 탐색적 연관성을 추정합니다.
5. **트리**: seed=42, 층화 학습 70%/검증 30%, max_depth=3, min_samples_leaf=40. 불균형 가중치는 적용하지 않습니다. 학습 규칙과 검증 집단의 관찰 비율을 함께 보고 재현성을 점검합니다. 중요도는 불순도 감소 기여도이며 인과적 순위가 아닙니다. 작은 검증 리프는 불안정합니다.
6. **정책 제안**: 근속≤2년, 초과근무 Yes, 만족도≤2, 승진대기≥5년, 동일 직급 급여 하위 25%를 사전 정의했습니다. 집단 대 나머지 직원 Fisher 검정에 별도 Holm 보정을 적용합니다. 표본≥30, 양의 비율 차이, 보정 p<.05일 때만 우선 점검합니다. 집단은 중복되며 탐색 후 정의를 바꾸면 새로운 검증이 필요합니다. 보상 하위 집단을 저보상으로 단정하지 않습니다.

## 대시보드

1. Workforce Overview: 지표, 퇴사/재직 특성, 전처리 진단
2. Attrition Diagnosis: 집단별 분모·비율·오차막대·HR 해석
3. Statistical Analysis: 가설·검정·효과크기·판단 및 CSV 다운로드
4. Attrition Drivers: 조정 OR·VIF·트리 시각화·학습/검증 규칙
5. HR Action: 집단별 근거, 우선순위, 정책 점검안, 후속 측정 지표
